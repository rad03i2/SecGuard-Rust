# Security Policy

SecGuard is intended only for systems you own or are explicitly authorized to assess. Port scanning may be restricted by policy, contract, or law; authorization is the operator's responsibility.

## Reporting a vulnerability
Please use GitHub's private security reporting feature when available. Do not publish credentials, private targets, tokens, or exploit details in a public issue.

## Scope
The project performs TCP connection checks, limited banner reads, and optional standards-based TLS handshakes. It does not exploit services, bypass authentication, or attempt credential access.
